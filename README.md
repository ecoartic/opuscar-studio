# Opuscar Studio

A Persian landing page: gallery of the 98 Lemo-Opuscar film styles plus a prompt builder for making a film in each style with Claude Code.

Thumbnails and linked demo films: [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) by Lemomo (LemoLab), CC BY 4.0, resized and compressed.
