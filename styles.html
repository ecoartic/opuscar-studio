استودیو سبک‌های فیلم

۹۸ سبک فیلم کوتاه که با کد ساخته می‌شوند، بدون مدل ویدیویی (۳ سبک برای تصاویرشان یک image generator هم لازم دارند). سبک را انتخاب کنید، داستانتان را بنویسید و پرامپت آماده‌ی ساخت را بگیرید.

چطور فیلم ساخته می‌شود؟

این صفحه پرامپت را می‌سازد؛ خود فیلم را Claude Code با پلاگین Lemo-Opuscar می‌سازد (هر فیلم حدود ۳۰ تا ۶۰ دقیقه). یک‌بار نصب کنید:

claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab

بعد Claude Code را باز کنید (/effort high) و پرامپت کپی‌شده را بدهید. پیش‌نیازها: Node 20+، ffmpeg 7+، Python 3.11+.

برای ایده و نقطه‌ی شروع، کتابخانه‌ی پرامپت‌های واقعی را ببینید: ۷۰۳ پرامپت منتشرشده از سازنده‌ها با لینک پست اصلی و ریمیک.

شفافیت ساخت: فیلم‌ها از صفحه‌های canvas و WebGL فریم‌به‌فریم رندر می‌شوند؛ نه مدل ویدیویی، نه فوتیج آماده. موسیقی از کتابخانه‌های sample رایگان و راوی با TTS است. سورس کامل هر فیلم در پوشه‌ی films/<name>/ می‌ماند و قابل بررسی است.

استثنا: سبک‌های Manga Panels، Text Flash Cuts و Comic History Cartoon برای تصاویرشان یک image generator لازم دارند (مثلاً Codex CLI)؛ این سبک‌ها در گالری برچسب «نیاز به image generator» دارند.

این سبک برای تصاویرش یک image generator لازم دارد (مثلاً Codex CLI). بقیه‌ی فیلم با کد ساخته می‌شود.
